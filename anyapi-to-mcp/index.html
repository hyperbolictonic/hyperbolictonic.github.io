Any API
→ MCP

Turn a REST API into something an agent can navigate instead of something it has to read. One declarative map per API, five verbs to move through it, and every response stored behind an address.

Quick start Source on GitHub npm package
 wrap2mcp
$ wrap2mcp ls
/dummyjson

$ wrap2mcp describe products.list
# inputs, view, mutating flag, links

$ wrap2mcp run products.list limit=3
# 3 rows · handle r_… · address /products

$ wrap2mcp read r_… /products/1
# no network call

Navigate, not enumerate

A multi-megabyte OpenAPI document costs tokens before the agent has done anything. A map is bounded: resources, the operations on them, and how each response should be presented. The agent asks for what it needs next.

lschildren, one line each
findranked search across the map
describethe input contract, on demand
runexecute; rows + meta + handle
readdrill into a stored payload

There is deliberately no cd: every address is absolute, so transcripts replay and subagents do not inherit hidden state.

What you get

maps

One map per API

Resources, operations, links and views in a versioned document. Import OpenAPI 3, or learn a shape from one live call.

 handles

Drill-down is free

Responses are stored behind content-addressed handles. A follow-up read costs no network call; handles expire.

 pins

Saved queries

A pin names an operation, its arguments and an address. read @name resolves it again, in any later session.

 writes

A real write gate

Anything but GET/HEAD is previewed first. confirm, open or deny per workspace; no automatic retries.

 secrets

Names, never values

A map names a credential; a human binds it to exactly one host. No tool call can create a binding.

 standalone

CLI, library, MCP

No Electron, no local bridge. The same verbs from a shell, a stdio MCP server or an import in your own code.

Quick start

Node 22 or newer. Run the published package without installing it, or add it to an MCP client.

npm
$ npx -y anyapi-to-mcp ls \
    --workspace ./workspace.json

$ npx -y anyapi-to-mcp describe products.list

$ npx -y anyapi-to-mcp serve \
    --workspace ./workspace.json
mcp client config
{
  "mcpServers": {
    "wrap2mcp": {
      "command": "npx",
      "args": ["-y", "anyapi-to-mcp",
               "serve",
               "--workspace", "./workspace.json"]
    }
  }
}

Write a map

Hand-write one, import an OpenAPI 3 document, or learn a draft from one live call.

Point a workspace at it

workspace.json names the map directory, the payload cache and the write policy.

Connect the agent

serve speaks stdio MCP. The agent navigates with ls, find, describe, run and read.

Where it fits

Standalone by design. A library, a CLI and an MCP server over the same verbs. No host application, no Electron, no bridge process in the core.

An alpha, built in the open. The API, file formats and tool schemas may change; the alpha banner on the repository says so plainly.

Experimental alpha software

Not production-ready. Try it, break it, and file issues. The published package is anyapi-to-mcp@0.1.2; the CLI is wrap2mcp.
